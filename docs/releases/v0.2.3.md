# NavHub v0.2.3 发布说明

NavHub v0.2.3 是在 v0.2.2 静默 SSO 之后的安全和体验补丁。它堵住了 SSO 用户名接管与 favicon CGNAT SSRF，让会话在改角色/删用户时立刻失效；壁纸切换不再闪纯色；弹窗、拖拽、小组件和中文界面也做了一轮打磨。

## 安全与会话

- 用户名冲突不再改写已有账号的邮箱/`casdoor_id`。
- Favicon 代理拒绝 CGNAT（含阿里云 metadata 网段等）并收紧搜索拉取范围。
- 降权、删用户会清 Redis 会话；过期会话 Cookie 会被摘掉。
- OIDC 可 discovery；支持 ES256；SSO 配置默认关闭；后台不回传 client secret。

## 体验

- `127.0.0.1` 与 `localhost` 进 SSO 前归一；回调失败回到登录界面，不再吐 JSON。
- 壁纸：旧图留到新图解码完再淡入；失败重试不清空。
- 浮层互斥、拖拽合并高亮、添加图标失败提示。
- 新小组件「系统状态」「今日站点」；搜索/日历/健康/空态优化。
- 默认简体中文，减少中英混用。

## 升级说明

- 无数据库迁移。
- 可直接用 `v0.2.3` 镜像替换。

```bash
docker pull ghcr.io/xjfyt/navhub:v0.2.3
```

## 验证

- 前端 Vitest：428+ 项通过（发布前本地跑过）。
- 后端相关单测与 SSO/安全改动配套通过。
- Docker 发布工作流将构建 `linux/amd64` 与 `linux/arm64`，并推送 `v0.2.3` 与 `latest`。
