# NavHub v0.2.2 发布说明

NavHub v0.2.2 是一次以 SSO 体验和官方镜像可构建性为重点的补丁版本。应用会话过期后，只要身份提供方仍保持登录，就会像 Outline 一样用 `prompt=none` 自动重登并回到原页面；IdP 已退出则回退交互登录，不会循环。同时将运行时基础镜像改为 Debian bookworm，并修复 Compose 中 Postgres 健康检查变量名错误。

## 核心变化

### 1. SSO 静默续期

- 登录入口支持 `GET /auth/login?prompt=none&return_to=...`（保留 CSRF state、PKCE、nonce）。
- 回调写入新的 `nh_sid` 后跳转到清洗过的站内路径。
- IdP 返回 `login_required` 一类错误时，回到 `return_to?nh_sso=interactive`，不再自动重试。
- 前端在已使用过 SSO 的情况下，冷启动或 `/api/me` 401 会触发静默重登；账号密码会话不会走这条路径。
- 认证请求会滑动刷新 Redis TTL；Cookie Max-Age 最多每 60 秒重写一次，会话仍有限。

### 2. 镜像与 Compose

- 运行时基础镜像：`debian:bullseye-slim` → `debian:bookworm-slim`，apt 加重试，避免旧源 502 导致构建失败。
- Postgres 健康检查改用 `POSTGRES_USER` / `POSTGRES_DB`。
- 新增 `docker-compose.sso-dev.yaml` 与 mock IdP（`alice` / `alice`），便于本地复现静默续登。

## 升级说明

- 不包含数据库迁移。
- 不需要修改现有配置文件。
- 可以直接使用 `v0.2.2` 镜像替换旧容器。

```bash
docker pull ghcr.io/xjfyt/navhub:v0.2.2
```

## 验证结果

- 后端 Rust 单元测试：151 项通过。
- SSO 端到端：`scripts/mock-oidc/e2e_sso.py` 通过（交互登录、会话过期 401、`prompt=none` 静默续登、IdP 登出后不循环）。
- 官方 `navhub` 镜像已在 bookworm 基础上本地构建验证。
- Docker 发布工作流将构建 `linux/amd64` 与 `linux/arm64` 镜像，并同时推送 `v0.2.2` 和 `latest` 标签。
